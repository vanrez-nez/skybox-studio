Compression quality for the lossy formats (JPEG and WebP). Higher keeps more detail at a larger file
size. PNG is lossless, so quality does not apply.

Note: JPEG has no transparency — image layers with alpha composite onto black. Use PNG or WebP to
keep transparency.
